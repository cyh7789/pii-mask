# pii-mask｜個資遮罩小工具

把客戶來信、訪談紀錄、員工名冊裡的個資換成代號，貼給 AI 之前先遮好；拿到回覆後，再把代號換回原本的資料。全部在瀏覽器裡處理，文字不會上傳到任何伺服器。

直接使用：https://cyh7789.github.io/pii-mask/

## 使用步驟

1. 原文貼在左邊，按「去識別化」。
2. 看一下「可能是姓名」。模型找到的名字已經先勾好，不是人名的就取消；規則找到的（例如「鄭先生」）要自己決定勾不勾。
3. 手上有員工或客戶名單，就貼到「補上名單」，名單裡的名字一定會遮。
4. 複製右邊的結果，貼給 AI。
5. AI 回覆後貼到「還原」，按「還原」換回真實資料。
6. 想之後再還原，可以下載對照表（CSV），下次上傳就能用。

## 會遮哪些資料

| 資料 | 怎麼找 |
|---|---|
| 身分證、居留證、統一編號 | 格式＋檢查碼 |
| 手機、市話（含 +886）、Email | 格式 |
| 銀行帳號、生日、護照、LINE | 前後有「帳號」「生日」「護照」「LINE」這類字 |
| 地址 | 縣市、區、路街、門牌；「住在」「住址」後面的地點 |
| 公司名稱 | 有限公司、工作室、企業社這類結尾；政府機關不遮 |
| 人名 | 中研院 CKIP 中文人名辨識、名單、「姓名：」「申請人：」這類欄位 |
| 表格 | 貼上 CSV 或 Excel 表格時，依第一列標題整欄處理 |

## 送出前請再看一遍

- 組合起來才認得出是誰的描述，例如「板橋門市副店長、2023 年到職」，工具不會處理。
- 模型偶爾會把一般詞當成人名，也可能漏掉全大寫的外籍姓名或英文名字。
- 代號能換回去，前提是 AI 沒有改動代號。還原後請核對一次。

## 下載後離線使用

- 雙擊 `index.html` 就能用規則和名單，但瀏覽器不允許讀取模型檔，人名辨識不會啟動。
- 要連模型一起用：在資料夾裡執行 `python3 -m http.server 8000`，再打開 http://localhost:8000 。

## 測試

`tests/corpus/` 有兩組虛構文件（18 份、138 個個資），以及每份文件該遮、該留的答案。

- `python3 tests/run_corpus.py`：用 Chrome 實際跑一次並計分
- `node tests/rules.cjs`：規則測試
- `node tests/chrome-smoke.mjs`：模型載入、雙擊開檔、沒有對外連線的檢查

目前成績（不貼名單、使用模型）：第一組 87 個遮掉 86 個，第二組 51 個遮掉 48 個；18 份文件還原後都和原文一字不差。
